# Scale with Ads

Next.js funnel site for [scalewithads.us](https://scalewithads.us).

## Routes

- `/` — main hub
- `/leadpilot` — Lead Pilot (personal ads management)
- `/metads` — LTO Meta Ads VSL
- `/privatemastermind` — Hidden Facebook Interest mastermind
- `/book` — application form
- `/outreach` — private cold email system (setup: [OUTREACH.md](OUTREACH.md))

## Develop

```bash
npm install
npm run dev
```

Review videos stream from the original CDN. The funnel VSL videos (`public/media/videos/*.mp4`) are bundled with the app so they work on the deployed site.
